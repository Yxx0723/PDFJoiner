## 七、已知问题与未完成事项

1. **数字签名**：旋转会重新序列化文档，签名必然失效，界面与文档卡已提示；结论来自 PDF 规范，**未用真实签名样本实测**。
2. **交互表单 / 附件 / 文档级 JavaScript / 页面标签**：旋转不新建文档，理论上这些结构仍在，但**没有单独样本实测**，不作保留承诺。已实测的是书签（`/Outlines` 保留）与页面注释（`/Annots` 保留）。
3. **超大输出**：超过 64 MB 的输出跳过二次解析校验，界面会明确标注「未做二次解析校验」；该分支仅由单测参数覆盖，未做真实大文件压测。
4. **一次一份 PDF**：V1.3 不支持同时旋转多份文件后分别下载 / 打包。
5. **输出命名固定**：`原名_rotated.pdf`，不提供自定义文件名。
6. **撤销栈 60 步**：更早的历史会被丢弃（当前状态始终保留）。
7. **缩略图**：旋转后该页需重新渲染，有极短暂 loading；600 页以上文档未做性能压测。
8. **`/Rotate` 语义**：只改页面旋转属性，不改 MediaBox；要求物理宽高也被交换的下游场景不满足。
9. **真机兼容**：真实 Edge、桌面 Safari、iOS Safari 未验证；中文 / 复杂字体 PDF 的旋转预览未逐页比对。
10. **非 90° 倍数 `/Rotate`**：明确拒绝而非容错，以避免角度语义不确定。

## 九、结论

V1.3 的旋转功能已在 `main` 上完成：**真实 PDF 处理（`/Rotate`）、实时预览、单页 / 选页 / 范围 / 全篇旋转、撤销重做、恢复原始方向、Worker 后台导出、进度与取消、输出逐页校验、下载闭环**全部可用。原有合并、图片转 PDF、拆分三个功能在三内核全量回归中保持通过。所有测试与构建结果均为真实执行，未验证项已在第七节如实列出。
